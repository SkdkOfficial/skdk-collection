# SK&DK COLLECTION

A starter Android shopping app for SK&DK COLLECTION. This first version is a UI prototype and uses local demo products only.

## Current scope
- Blue-and-yellow shopping UI inspired by familiar e-commerce patterns
- Home, categories, product cards, cart and account sections
- No Supabase or admin panel yet, as planned
- Demo products and prices are placeholders

## Build
Open the repository in Android Studio or connect it to Codemagic using the included `codemagic.yaml`.

Package name: `com.skdk.collection`
